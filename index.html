Pasos para Desplegar en Vercel

Cómo publicar este repo en la nube

Sigue estos pasos sencillos para conectar tu repositorio local con Vercel:

1
Subir este repositorio a GitHub (ej: git push origin main).
2
Ingresar a vercel.com/new y seleccionar el repositorio.
3
Hacer clic en Deploy (Vercel detectará el proyecto de forma automática).
O despliega directamente con Vercel CLI:
npx vercel
